# 日期字段内容过长造成视觉重叠

## 现象

固定宽度的日期字段中，模型把完整日期（例如 `2024年04月15日`）写入“结束日期”单字段，模板外层又追加“日”，结果出现日期重复并超出下划线区域。

## 根因定位

对 `BP-C3152R_20260804_145128` 的原始识别 TeX、reconcile TeX 和 optimized TeX 逐级比较后，重复内容在识别结果中已经存在；reconcile 和优化只保留并标注该字段，没有复制日期。属于字段语义切分错误，不是 XeLaTeX 或重复优化造成的。

## 已尝试方案

- 重启或重复优化：会复用同一识别结果，重复问题不变。
- 全局截断日期字段：会损坏其他文本字段，且无法判断哪部分应保留。
- 自动按日期正则拆分：复杂表单中日期可能是手写文本、范围或非标准格式，误拆风险高。

## 当前处理

识别提示词要求日期范围拆成“年、月、日”三个独立字段；编译链路只保证字段可编译和位置稳定，不擅自改写手写内容。对已生成结果，需重新识别该页或人工确认后再发布。

## 限制

手写内容准确率不是当前发布门槛，但过长内容会影响版式。后续可增加基于字段宽度的视觉溢出告警，告警后升级该页，而不是静默截断。
