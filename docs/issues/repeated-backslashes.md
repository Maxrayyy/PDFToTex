# 重复或奇数次反斜杠

## 现象

表格横线前出现三条或更多连续反斜杠，XeLaTeX 报 `Misplaced \\noalign`；错误位置通常指向 `\\hline`，真正原因在上一行结束符。

## 已尝试方案

- 全局压缩连续反斜杠：会破坏 TeX 命令、字段中的原文和嵌套表格。
- 只替换 `\\hline`：没有恢复上一行的合法边界。
- 允许流程继续执行结构错误：坏结果进入缓存，容器每次重启都重复失败。

## 当前方案

只在紧邻 `\\hline` 的表格物理行边界收敛多余行结束符，其他位置不改；修复后重新执行结构校验和编译，失败则回退安全版本。

## 限制

普通文本中的反斜杠和嵌套表格无法仅凭全局字符串规则区分，必须依赖表格上下文。

## 验证

回归测试覆盖奇数行结束符、合法字段内容和 `\\hline` 边界；通过后才允许发布。
