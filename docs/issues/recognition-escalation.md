# 识别升级页过多

## 现象

本地视觉识别后，很多页面被列入“仍需 GPT-6 处理”，即使最终版面并不一定需要逐页重写。

## 已尝试方案

- 单纯降低升级阈值：会把低置信度结构错误带入 TeX。
- 只依赖提示词要求模型少升级：页面复杂度和字段密度仍会造成保守判断。
- 反复重启队列：不会改变已缓存的识别判定。

## 当前原则

升级依据应优先使用结构校验、编译结果和视觉布局风险；手写文字识别错误可以保留，只要不破坏印刷体位置、表格结构和编译。升级失败时保留安全的本地结果并记录原因。

## 限制

复杂表单的“内容正确”与“版式正确”无法由单一置信度阈值表达，需要结合页级结构指标和最终 XeLaTeX 结果评估。
