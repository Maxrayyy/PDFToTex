# 大括号与 `\\parbox` 参数错位

## 现象

语法修复后出现多余或缺失 `}`，`\\fieldvalue`、`\\handwritten`、`\\makebox` 或 `\\parbox` 参数错位，导致编译失败或字段内容跑位。

## 已尝试方案

- 让模型返回整页修正版：修改范围过大，常同时破坏表格行和字段边界。
- 按字符数量补 `}`：无法判断闭合目标，可能把错误传播到后续页面。
- 关闭结构校验继续优化：错误被缓存，重启无法自愈。

## 当前方案

语法模型只能返回局部、连续、整行替换；每次替换后确定性检查大括号和 `\\parbox` 参数。校验未改善时回退到替换前文本，再触发视觉升级或保留原稿。

## 限制

手写内容中的任意字符不能作为 TeX 结构推断依据；修复目标是可编译和版式稳定，而不是猜测手写文字。

## 验证

单元测试覆盖嵌套字段、缺失闭合括号和模型候选回退；发布前执行双遍 XeLaTeX。
