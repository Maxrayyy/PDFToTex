# 模型服务不可用导致队列暂停

## 现象

识别阶段出现 `ModelServicePaused`，队列保留已完成进度并暂停后续 PDF；容器通常以非零状态退出。

## 已尝试方案

- 反复重启：若模型缓存损坏、网络失败或 API 503 未改变，结果会重复。
- 仅检查镜像依赖：镜像内安装 PaddleOCR 不等于模型初始化或请求成功。
- 更换密钥但保留旧中间结果：可能继续读取失败缓存，无法验证新配置。

## 当前诊断

先查看 `recognize.process.log` 与 `recognize.calls.jsonl`，区分初始化/下载、进程崩溃、网络超时、限流、认证和服务端 5xx。只在确认根因后重建或重试，并保留已完成页。

## 限制

外部模型服务的 503、限流和网络故障无法由 TeX 代码修复；程序应暂停并保留进度，避免发布不完整结果。
