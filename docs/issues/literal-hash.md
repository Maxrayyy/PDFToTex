# 表格正文中的字面 `#`

## 现象

U3 的 `MX-C4081R_20260806_132025.pdf` 优化编译在第 68 页失败：

```text
You can't use `macro parameter character #' in internal vertical mode.
... line 10748: #### &
```

识别结果把流式细胞表格中的 `####` 作为普通正文输出。TeX 中 `#` 只能出现在宏定义参数或转义为 `\#` 后的正文中。

## 尝试与修复

1. 仅重启容器无效，因为同一 reconciled TeX 会再次生成 `####`。
2. 全局替换 `#` 会破坏 `\newcommand`、支持宏和 `#1` 参数；布局测试也会出现 `Illegal unit of measure`。
3. 当前方案逐行只处理正文区域的未转义 `#`，保留 `\#`、注释、宏定义行以及 `% >>> lexoid ...` 到 `% <<< lexoid ...` 的生成支持块。

## 验证

- 红灯样本使用真实表格行 `Population & #### \\`，同时包含 `\newcommand{\\sample}[1]{#1}`。
- 完整回归：流水线 366 项、Lexoid 142 项、3 个子测试通过。
- 修复后 `####` 输出为 `\#\#\#\#`，支持宏参数保持 `#1`。
