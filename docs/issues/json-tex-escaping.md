# JSON 与 TeX 反斜杠转义

## 现象

模型返回的 JSON 字符串直接包含 `\\fieldvalue`、`\\textbf`、`\\times` 等命令时，解析器可能把 `\\f`、`\\t` 当作控制字符，产生 `Invalid \\escape` 或内容损坏。

## 已尝试方案

- 先用普通字符串替换反斜杠：容易二次转义，合法 JSON 也会被破坏。
- 让模型自行保证转义：模型输出不稳定，无法作为程序边界约束。
- 解析失败后整页重试：增加请求成本，且不能修复系统性的编码误读。

## 当前方案

在 JSON 解析前只保护已知多字母 TeX 命令，解析后恢复并执行字段/TeX 校验；原文反斜杠按文字保留，不把手写内容当作命令。

## 限制

未知或截断的 TeX 命令仍可能触发解析失败，应记录原始响应并暂停该页，不能静默丢弃字段。
