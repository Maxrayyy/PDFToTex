# 整页复核重复消耗

## 根因

纯 TeX 识别路径生成的字段坐标可能是整页占位坐标。旧版逐字段以 480 DPI
裁图，因此同一页的多个异常字段会重复发送整页图片，而不是局部裁片。

## 处理方式

- 坐标必须有效、位于页面内，且加入裁图边距后的面积小于页面面积的 90%，才走局部复核。
- 缺失、非法或接近整页的坐标按页合并，一张图片对应该页全部待复核字段；附带字段 ID、标签、初始值和页面上下文。
- 返回结果必须包含全部请求 ID，且不得重复或夹带其他 ID。校验失败不退回逐字段整页调用。
- 成功响应增量写入 `*.reconcile-cache.json`，重复运行优先复用。
- `*.reconcile-budget.json` 在请求前预留次数，按源 PDF 哈希和页码计数，使用独立锁文件保护并发更新。
  失败和中断也占次数；重启、字段变化、模型变化或 DPI 变化不重置上限。
- CLI 参数 `--max-page-requests` 默认 2，可选 1 至 3。账本损坏时禁止新增整页调用，不能通过自动清空账本继续花费。
- 达到上限、返回不确定或服务失败时，保留原值及人工复核标记，并记录错误；不将未复核字段算作确认通过。
- 保留原有字段筛选策略；`--review-content` 才扩展到内容复核，本修复不扩大自动确认范围。

次数账本与字段输出放在一起，重跑应沿用同一输出路径。不要为绕过上限删除账本或换输出目录。

## 日志

调用明细写入 `LEXOID_MODEL_CALL_LOG` 指定的 `*.calls.jsonl`，不写入日报逐条展示。
包含页码、字段 ID/数量、复核原因、局部/整页方式、图片尺寸/字节数/DPI、
整页请求序号、耗时、Token 用量和估算费用。另记录分组计划、缓存命中和校验结果。
不记录请求密钥或图片 Base64。

价格默认读取打包的 `texopt/model_prices.json`，可用 `RECONCILE_PRICING_FILE` 指定价格文件。
费用仅为估算；缺失用量或价格不可用时记录未知值，不冒充零费用。日报仍使用原有汇总逻辑。
