# Web 工作台隔离执行并复用流水线

状态：accepted；历史回填于 2026-10-20。

Web 使用独立任务目录、SQLite 任务库和容器归属，复用既有 `BatchConfig` / `run_batch`，不接管或改写生产队列。默认同时执行一个文件，文件内识别页并发默认为一并可配置；文件夹上传解析所有 PDF 后按清单排队。按既定产品选择不增加账号权限体系。

纯 TeX 编译不调用模型，不需要模型凭据；在独立的无网络容器中两遍编译。转换和纯编译共用 Web 执行槽。输入配置按任务保存，产物按执行尝试留版本，已有结果重新编译创建新任务，不能把旧成功 PDF 当作本次成功。

这个分离避免网页配置和失败影响持续运行的转译方式，也明确了停止、重试和凭据的归属。任务库记录执行意图，阶段状态库记录流水线事实，两者不相互直接改写。

证据：主仓库 `4bbc09f`、`e454a97`、`29647fd`；`docs/WEB_DESIGN.md`、`web/backend/store.py`、`worker.py`、`runner.py`。历史的 `pipeline/app.py` 是另一个可选入口，不代表当前工作台的架构。
