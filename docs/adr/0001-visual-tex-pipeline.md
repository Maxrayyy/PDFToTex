# 以视觉识别和 TeX 为主链路

状态：accepted；历史回填于 2026-10-20。

源 PDF 通过视觉识别生成带字段标记的 TeX，再做确定性归一化、按需页面升级、字段协调、优化和编译。保留当前视觉链路，不另建结构化表格中间格式；已有 OCR/方向信息用于检查和证据定位，不作为重建整份记录的替代主链路。

选择 TeX 是为了保留可编辑文本、表格和 SyncTeX 定位能力。代价是必须显式处理宏、数学模式、列规格与编译兼容性，不能把这些问题转成不可编辑的整页截图。实验图片/曲线的内容范围由识别规则决定；历史上先省略重绘、随后明确保留数据图空框，不应根据旧提交恢复已撤销的输出规则。
