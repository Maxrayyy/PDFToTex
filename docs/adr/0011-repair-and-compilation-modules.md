# 修复接受与版面验收分别内聚

状态：accepted；2026-10-20 架构改进。

候选文本的接受、定向重试和回退由 `RepairTransaction` 管理；最终 TeX 的准备、两遍编译、几何检查和有限调整由 `compile_document` 管理。CLI 保持参数和退出码职责，不再持有两套内部编排。

两个模块分别回答“候选能否用于后续处理”和“最终版面能否交付”，不合并成一个更大的协调器。模型生成器及缓存保留在修复流程内部，编译模块返回独立结果而非要求调用者读取被原地修改的报告。测试走这些行为入口，保留真实 XeLaTeX 和几何回归。

这一改进不改变 ADR-0004 的字段政策，也不把 Web 纯编译变成隐含优化。证据：主仓库 `2254403`、`f24eb66`；`test_repair_transaction.py`、`test_compilation.py`、`test_page_layout.py`；2026-10-20 架构检查和用户授权依次落实。
