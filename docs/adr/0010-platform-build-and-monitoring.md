# 平台化构建与监控配置

状态：accepted；历史回填于 2026-10-20。

Linux 服务器与 macOS 本机共享流水线行为，平台差异集中到构建、镜像架构和调度配置。依赖运行时与工作镜像分开，配置决定镜像标签、目录和部署参数；不通过更改业务代码里的机器路径切换环境。

启动批次后必须确认监控调度及业务快照实际更新。Mac 本地执行与 Mac 观察服务器是不同模式，后者沿用服务器账本。这避免“容器已启动”被误当作运行保障已就绪，也避免平台迁移建立重复统计。

证据：主仓库 `379740a`、`e4be063`、`ad7d2e4`、`260910b`、`bf5d988`、`8001674`；`deploy/platforms/`、`scripts/build-images.sh`、`scripts/monitor.py` 与 AGENT.md。
