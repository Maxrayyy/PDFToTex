# 按证据恢复并限定自动重启

状态：accepted；历史回填于 2026-10-20。

任务恢复依据阶段状态、输入/配置指纹与产物，保留已完成识别和模型缓存；服务中断不能被当作成功识别，也不能清空整个批次重新消费模型调用。队列按既定顺序执行，失败状态未解决前不跳过当前批次。

临时模型服务错误采用 3、6、12、24、48、96 分钟间隔，每份 PDF 最多六次自动重启；认证错误、OOM 和编译错误不进入该序列。重启前及启动成功或失败都要记录通知结果和次数。旧监控只管理旧队列，Web 执行器只管理自己的容器，防止重复重启。

证据：Lexoid `90adfdb`；主仓库 `638b878`、`9b28524`、`c5f53da`、`7bd6c0d`、`df32637`、`0e41217`、`4bbc09f`。实现见 `runtime/pipeline_state.py`、`runtime/stages.py`、`monitoring/worker_watch.py` 和 `web/backend/worker.py`；间隔与目录从部署配置读取。
