# 代码与运行资料分别归属

状态：accepted；历史回填于 2026-10-20。

主仓库维护流水线、运行脚本、部署和 Web；Lexoid 保留独立 Git 子仓库。流水线曾是子模块，随后源码纳入主仓库并按识别、优化、运行和监控职责整理；保持 `texopt` 导入名及 `texopt` / `texopt-pipeline` 命令稳定。

原 PDF、缓存、正式产物、账本和临时修复资料保存在仓库外的 `Downloads/` 与 `data/`。它们不随源码重构移动，也不进入 Git。这个分离允许独立升级识别包，同时避免代码提交或目录整理改变生产资料。

证据：主仓库 `faaa52b`、`c784450`、`d47fc8a`、`51ae061`、`42cd3a8`、`ee58eda`；`docs/ARCHITECTURE.md`。历史旧路径可在 Git 中查到，但不再作为当前运行入口。
