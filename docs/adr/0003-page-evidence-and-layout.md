# 源页证据与输出页验收分开

状态：accepted；历史回填于 2026-10-20。

识别、字段坐标和裁剪统一使用方向校正及倾斜矫正后的页面几何信息；输出 PDF 则通过源页标记映射回源页。允许一张源页产生多张输出页，页数不严格一致本身不构成交付失败，但裁切必须失败。

因此不能把“总页数相同”作为正确性的充分条件，也不能仅凭 XeLaTeX 返回零就接受有裁切的文件。当前有限调整同时处理所有仍可调整的越界源页，最多三轮编译。该规则保留了长表和多页记录的内容，代价是必须维护页映射与几何检查。

证据：主仓库 `945a23a`、`6fd01e3`、`10a6727`、`af96b48`、`0f40b7a`；Lexoid `1139dab`、`3ba2ed1`。当前 `page_layout.py` 和 `compilation.py` 负责几何验收；`test_page_layout.py` 覆盖分页、裁切和源页映射。
